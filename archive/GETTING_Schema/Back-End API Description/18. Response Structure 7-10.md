**Update Follow-Up Action**

```
PATCH /api/follow-up/actions/{action_id}
```

Request Body

```sql
{
  "dueDate": "2024-12-22",
  "notes": "تم التأجيل لمدة 7 يوم في 2024-12-17",
  "status": "pending"
}
```

**Response Structure**:

```
{
  "success": true,
  "message": "Action updated successfully",
  "action": {
    "id": "ACT-2024-001",
    "actionTitle": "تدريب الطاقم على بروتوكول جديد",
    // ... full updated action object ...
    "lastUpdatedAt": "2024-12-17T11:30:00Z",
    "lastUpdatedBy": "user@hospital.local"
  }
}
```
