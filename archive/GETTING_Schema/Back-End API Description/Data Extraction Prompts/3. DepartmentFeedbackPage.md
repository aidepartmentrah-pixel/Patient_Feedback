Page Name:
Department Feedback / Explanations

Description:
This page is used by departments to provide explanations in two distinct contexts:

1) Incident Explanations (Tab 1):
   - Departments explain what happened for individual open incident/complaint records
   - Records are filtered, sorted, and flagged as delayed or overdue
   - Users open a record, view details, and submit an explanation with corrective actions
   - Action items may be generated and sent to a Follow-Up system

2) Seasonal Explanations (Tab 2):
   - Departments explain why performance metrics exceeded defined seasonal thresholds
   - Records represent aggregated seasonal violations (per department, per metric)
   - Users submit root-cause analysis and corrective actions for each violation

UI Components:
- Explanation type switch (Incident vs Seasonal)
- Filters (search, department, severity, status, date range)
- Open records table (incident-based)
- Seasonal violations table (aggregated metrics)
- Modal dialogs for:
  - Incident explanation form
  - Seasonal explanation form
- Forms with required fields:
  - Explanation text
  - Corrective actions
  - Action items
  - Responsible person
