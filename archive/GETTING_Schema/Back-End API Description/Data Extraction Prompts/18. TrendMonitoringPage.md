TrendMonitoringPage

This page is used for longitudinal trend analysis of incidents over time.

- Improvement trends

- Individual record inspection
- Editing

     - Tabular representation of the same data
     - One row per domain
     - One column per month
     - Values are aggregated counts

2. Category Trend Analysis:
   - CombinedCategoryChart:
     - Multi-line or multi-series chart
     - Shows monthly incident counts per CATEGORY
   - CategoryTrendTable:
     - Tabular representation
     - One row per category
     - One column per month

Important characteristics:
- Data is aggregated
- No patient-level or record-level identifiers are shown
- Values are counts only
- Charts and tables must be driven by the SAME dataset
