Page Name:
Insert Record

Description:
This page is used to create and submit a new feedback / incident record.
It follows a multi-step form (wizard-style), but submission happens once at the end.

Workflow:
1. User enters free-text complaint and actions
2. User fills structured metadata (departments, source, dates, etc.)
3. User optionally runs NER to extract patient/doctor names
4. User classifies the record (domain → category → subcategory → classification)
5. User submits the record to be stored as a new incident

UI Components:
- Text blocks:
  - Complaint text
  - Immediate action
  - Taken action
- Metadata fields:
  - Feedback received date
  - Issuing department (ID)
  - Target department(s) (IDs)
  - Source
  - In/Out indicator
  - Worker type
- NER output section:
  - Patient name (editable)
  - Doctor name (editable)
  - NER extraction trigger
- Classification fields (ID-based):
  - Domain
  - Category
  - Subcategory
  - Classification
- Additional attributes:
  - Severity
  - Stage
  - Harm level
  - Improvement opportunity
- Action buttons:
  - Run NER
  - Add Record (submit)
